# 네이버 뉴스 검색 API 스파이크 (NV-01)

2026-10-21 10:00 KST. 공식 문서([뉴스 검색](https://developers.naver.com/docs/serviceapi/search/news/news.md))와 실제 키로 확인했다. 계획서: [naver-search-plan.md](../naver-search-plan.md). 키 값은 기록하지 않는다.

## 1. 사양 확인

공식 문서와 실측이 일치했다. 인증은 `X-Naver-Client-Id`/`X-Naver-Client-Secret`, 응답은 `items[]`의 `title`·`description`(`<b>` 태그 포함)·`originallink`·`link`·`pubDate`(`Wed, 21 Oct 2026 09:42:00 +0900`, KST)이고 최상위에 `total`, `lastBuildDate`가 있다. 날짜 범위 필터와 언론사 이름 필드는 없다.

## 2. 실측

| 질의 | 설정 | 응답 시간 | 결과 |
|---|---|---|---|
| 코스피 마감 시황 | sim 10건 | 0.1초 | 뉴스1·연합뉴스TV·뉴스핌·서울신문 등. **오늘 09:42 개장 시황 포함** |
| 코스피 마감 시황 | date 10건 | 0.1초 | 오늘 09:12~09:42 개장 시황이 앞에 옴 |
| YTN 증시 코스피 | date 50건 | 0.1초 | 50건 중 44건이 ytn.co.kr 원문 (최신 10-21 06:39) |
| 코스피 | date 100건 | 0.1초 | 100건 모두 오늘 기사 |
| Nvidia earnings | date 10건 | 0.1초 | 영어 질의도 결과 있음 (econotimes, 코리아중앙데일리) |
| S&P 500 마감 | date 10건 | 0.1초 | `&` 포함 검색어도 정상 |

- 응답이 0.1초로 Tavily(1~6초)보다 훨씬 빠르다.
- Tavily 기반 폰 검증에서 "오늘 장 상황은 확인된 자료가 없다"고 한 질문에, 네이버는 오늘 개장 시황(코스피 3% 반등, 5700선 회복)을 바로 돌려준다.
- 요약(`description`)은 118~198자로 짧다.

## 3. 정렬·거름 전략 근거

검색어별로 50건을 받아 최근성과 관련도를 비교했다(관련 = 제목·요약에 검색어 핵심어가 있음).

| 검색어 | 정렬 | 24시간 이내 | 7일 이내 | 관련 |
|---|---|---|---|---|
| 코스피 마감 시황 | sim | 22 | 50 | 50/50 |
| 코스피 마감 시황 | date | 25 | 50 | 50/50 |
| 삼성전자 실적 | sim | 34 | 50 | 50/50 |
| 삼성전자 실적 | date | 50 | 50 | 50/50 |
| 최근 부동산 대책 | sim | 13 | 47 | 50/50 |
| 최근 부동산 대책 | date | 50 | 50 | 50/50 |
| 서울 날씨 한파 | sim | 8 | 14 | 50/50 |
| 서울 날씨 한파 | date | 12 | 26 | 50/50 |

- `sort=date`로 받아도 관련도가 떨어지지 않았다(50/50). 기간을 지정하면 `date`로 50건을 받아 거르는 편이 24시간·7일 이내 건수가 같거나 많다.
- 기간 지정이 없으면 `sim`이 정확도 순이라 적합하다.
- YTN 지정은 `date`로 받아 `originallink` 호스트로 거르면 최신 YTN 기사가 먼저 나온다(최신 10-21 06:39).

## 4. 계획 반영

1. 기간 지정(`recency`) 있음: `sort=date`, `display=50` → 발행일로 거름(day=최근 24시간, week=7일, month=30일) → 상위 5건.
2. 기간 지정 없음: `sort=sim`, 5건.
3. 매체 지정(`site`): `sort=date`, `display=50` → `originallink` 호스트(서브도메인 포함)로 거름 → 상위 5건.
4. 거른 결과가 5건 미만이면 있는 만큼만 돌려준다. 0건이면 "결과 없음"으로 알리고 재검색은 규칙이 맡는다(`sim` 재요청은 하지 않는다).
5. `pubDate`는 네이버 제공 시각이라 기사 작성 시각과 다를 수 있다.
