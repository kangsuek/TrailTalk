# 응답 지연 테스트 시나리오 (말할 내용)

> 목적: 서버가 `turn_latency`(DB)와 `턴 지연(…)` 로그로 남기는 구간별 시간을 조건별로 모은다. 한 시나리오는 한 가지 조건만 바꾼다.
> 진행: 시나리오 하나가 끝나면 Claude에게 "A 끝"처럼 알린다. 로그 시각으로 구간을 나눠 분석한다.

## 공통 규칙

- 이어폰을 끼고 조용한 곳에서 한다(H만 예외). 폰 모드(`./run.sh --phone`) 서버를 쓴다.
- 시나리오마다 **새 대화**를 시작한다(F·G는 대화 하나를 이어서).
- 제니의 답변이 **끝날 때까지 기다린 뒤** 다음 말을 한다(D·E 제외).
- 말은 또박또박 한 문장으로, 아래 문장을 그대로 읽는다. 문장이 달라지면 비교가 흐려진다.
- 표시: `[ ]`는 했는지 체크용이다.

## A. 기준선: 짧은 일상 질문 (새 대화 1개, 10턴)

조건: 한 문장 질문, 검색 없음, 끼어들기 없음.

1. [ ] "오늘 기분이 어때?"
2. [ ] "아침에는 뭘 먹는 게 좋을까?"
3. [ ] "산책할 때 어떤 음악이 어울려?"
4. [ ] "요즘 잠이 잘 안 오는데 어떻게 해야 해?"
5. [ ] "물은 하루에 얼마나 마셔야 해?"
6. [ ] "스트레칭은 언제 하는 게 좋아?"
7. [ ] "비 오는 날 산책해도 괜찮을까?"
8. [ ] "걷기 전에 준비운동이 필요해?"
9. [ ] "커피는 아침에 마셔도 될까?"
10. [ ] "오늘 하루 잘 보내자고 한마디 해 줘."

## B. 답변 길이 비교 (새 대화 1개, 짧은 5 + 긴 5)

조건: 같은 주제, 말투 지시만 다르다.

짧은 답변(5턴)
1. [ ] "걷기의 장점을 한 문장으로만 말해 줘."
2. [ ] "스트레칭의 장점을 한 문장으로만 말해 줘."
3. [ ] "수영의 장점을 한 문장으로만 말해 줘."
4. [ ] "요가의 장점을 한 문장으로만 말해 줘."
5. [ ] "자전거 타기의 장점을 한 문장으로만 말해 줘."

긴 답변(5턴)
6. [ ] "걷기의 장점을 자세하게 설명해 줘."
7. [ ] "스트레칭의 장점을 자세하게 설명해 줘."
8. [ ] "수영의 장점을 자세하게 설명해 줘."
9. [ ] "요가의 장점을 자세하게 설명해 줘."
10. [ ] "자전거 타기의 장점을 자세하게 설명해 줘."

## C. 검색 턴 비교 (새 대화 1개, 비검색 5 + 검색 5)

비검색(5턴)
1. [ ] "산책의 장점이 뭐야?"
2. [ ] "근육은 왜 아파?"
3. [ ] "깊은 호흡은 어떤 도움이 돼?"
4. [ ] "아침 햇볕은 왜 좋아?"
5. [ ] "스트레스를 푸는 간단한 방법 하나만 알려 줘."

검색(5턴, 최신 정보가 필요한 질문)
6. [ ] "오늘 서울 날씨 검색해서 알려 줘."
7. [ ] "이번 주 주요 뉴스 한 가지만 검색해서 알려 줘."
8. [ ] "지금 코스피 지수가 얼마인지 검색해서 알려 줘."
9. [ ] "오늘 미세먼지 상태를 검색해서 알려 줘."
10. [ ] "이번 주말 날씨를 검색해서 알려 줘."

## D. 끼어들기 (새 대화 1개, 10회)

조건: 제니가 말하는 중에 말을 끊고 새 질문을 한다. 먼저 제니가 길게 답하게 만든 뒤 끊는다.

준비 질문(제니를 길게 말하게 함): "아침 운동 루틴을 자세하게 설명해 줘."

첫 문장 도중에 끼어들기(5회) — 제니가 말하기 시작하자마자(1~2초 안에) 끼어든다.
1. [ ] 준비 질문 → 끼어들며 "아니, 저녁 운동 루틴으로 알려 줘."
2. [ ] 준비 질문 → 끼어들며 "잠깐, 짧게 말해 줘."
3. [ ] 준비 질문 → 끼어들며 "스트레칭만 알려 줘."
4. [ ] 준비 질문 → 끼어들며 "그건 알고 있어, 다른 거 알려 줘."
5. [ ] 준비 질문 → 끼어들며 "아니야, 그냥 오늘 날씨 얘기하자."

답변 후반에 끼어들기(5회) — 제니가 4~5문장째 말할 때 끼어든다.
6. [ ] 준비 질문 → 후반에 "알겠어, 그만 말해도 돼."
7. [ ] 준비 질문 → 후반에 "방금 한 말 다시 알려 줘."
8. [ ] 준비 질문 → 후반에 "고마워, 다음 질문 할게."
9. [ ] 준비 질문 → 후반에 "그럼 점심 메뉴 추천해 줘."
10. [ ] 준비 질문 → 후반에 "좋아, 끝내자."는 하지 말고 "다음 주제로 넘어가자."

## E. 이어 말하기 (새 대화 1개, 6회)

조건: 한 문장을 말하다가 1~2초 쉰 뒤 이어서 말한다. `…`가 쉬는 지점이다.

1. [ ] "오늘 일정이 좀 많은데… 오후에는 병원에 가야 하고 저녁에는 모임이 있어."
2. [ ] "내일 아침 일찍 산책을 하고 싶은데… 날씨가 어떨지 모르겠어."
3. [ ] "요즘 운동을 시작했는데… 무릎이 조금 아파."
4. [ ] "점심으로 뭘 먹을지 고민인데… 가볍게 먹고 싶어."
5. [ ] "주말에 등산을 가려고 해… 초보자도 갈 만한 곳이 있을까?"
6. [ ] "어제 잠을 못 잤는데… 오늘 컨디션을 어떻게 올릴까?"

## F. 긴 대화에서의 지연 변화 (새 대화 1개, 25턴 연속)

조건: 난이도가 같은 짧은 질문을 한 대화에서 계속한다. 턴이 늘수록 첫 글자가 늦어지는지 본다.
"끝말잇기"를 한다. 제니와 번갈아 단어를 잇는다.

1. [ ] "끝말잇기 하자. 내가 먼저 할게, 사과."
2~25. [ ] 제니가 말한 단어의 끝 글자로 이어서 한 단어씩 말한다. 25번을 채울 때까지 이어 간다. 막히면 아무 단어나 말해 이어 간다.

## G. 쉬었다가 다시 말하기 (새 대화 1개, 5회)

조건: 한 턴을 한 뒤 쉬었다가 다음 말을 한다. 쉬는 동안 화면은 그대로 둔다.

1. [ ] "안녕, 오늘 날씨 어때?" → 3분 쉼
2. [ ] "아까 이야기 이어서 해도 될까?" → 8분 쉼
3. [ ] "아침 운동 하나만 추천해 줘." → 15분 쉼
4. [ ] "다시 왔어, 잘 지냈어?" → 3분 쉼
5. [ ] "이제 정리하고 마무리하자."

## H. 소음과 짧은 말 (실제 산책 중 1번, 8회)

조건: 걸으면서 한다. 바람이 있는 곳이면 더 좋다.

1. [ ] "응."
2. [ ] "네."
3. [ ] 헛기침만 한 번
4. [ ] 숨을 크게 한 번 쉬기
5. [ ] "음…" 하고 말을 멈추기
6. [ ] "어, 잠깐." 하고 말을 멈추기
7. [ ] 걸으면서 "오늘 산책 코스 괜찮네."
8. [ ] 바람 소리 속에서 "지금 몇 시야?"

## 권장 순서

| 순서 | 시나리오 | 이유 |
|---|---|---|
| 1 | A | 기준선 |
| 2 | C | 검색 영향 분리 |
| 3 | D | 끼어들기 직후 지연·취소 대기 |
| 4 | F | 대화 길이와 첫 글자 관계 |
| 5 | B, E, G, H | 필요할 때 추가 |

A·C·D·F만 해도 정상 턴 약 55턴이 쌓여 구간별 중앙값과 p90을 낼 수 있다.

## 분석할 때 보는 값

- 구간: `stt`, `first_token`, `first_queued`, `first_synth`, `synth_wait`, `first_sentence`, `done`
- 조건: `chars`, `sentences`, `tools`, `search`, `resumed`, `cli_age`, `abort`
- 끼어들기: `끼어들기 정리`의 `wait`, `outcome`
- 한계: 첫 문장 글자 수와 대화 내 턴 번호는 기록되지 않는다. 로그 시각과 시나리오 순서로 나눈다.
