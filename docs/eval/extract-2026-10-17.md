  - O 부모가 미션을 주면 용돈을 주는 기능
  - O 조카에게 어떤 캐릭터가 좋은지 물어보기
- 추출(아이디어·할 일)
  - O [아이디어] 저금하면 캐릭터가 자라는 기능
  - O [아이디어] 부모가 미션을 주면 용돈을 주는 기능
  - O [할 일] 조카에게 어떤 캐릭터가 좋은지 물어보기
- 채점: 모든 항목이 정답과 뜻이 같고 대화에서 사용자가 직접 말한 내용이다. 저장된 노트가 없어 중복도 없고, 메모 목록도 비어 있다.

### 10. `memo-vs-todo` (13.5초)

- 설명: 기억할 정보(메모)와 할 일이 섞임. 메모는 아이디어·할 일 정답에 넣지 않는다
- 제목: 동네 도서관 휴관·반납과 빈자리 알림 생각 / 요약: 동네 도서관이 다음 달부터 월요일 휴관한다. 빌린 책은 이번 일요일까지 반납하기로 했다. 도서관 빈자리를 알려 주는 알림이 있으면 좋겠다는 생각이 들었다.

  - O 빌린 책을 이번 일요일까지 반납하기
- 추출(아이디어·할 일)

  - O [할 일] 이번 일요일까지 빌린 책 반납하기
- 채점: 모든 항목이 정답과 일치하고 대화에서 뒷받침되며, 이미 저장한 노트가 없어 중복도 없고 메모 목록도 비어 있음.

### 11. `saved-during-talk` (11.2초)

- 설명: 대화 중 할 일을 이미 저장함(괄호 맥락 붙음). 같은 할 일을 다시 뽑지 않아야 한다
- 제목: 동네 공원 반려견 놀이터 지도 만들기 / 요약: 동네 공원에 반려견 놀이터 위치를 모은 지도를 만들자는 아이디어를 이야기했다. 지도 만들기의 첫 단계로 이번 주에 공원 관리사무소에 문의하기로 했다.
- 대화 중 저장한 노트: [할 일] 이번 주에 공원 관리사무소에 문의해서 반려견 놀이터 위치 확인하기 (동네 공원 반려견 놀이터 지도 만들기 첫 단계)
- 정답
  - O 동네 공원의 반려견 놀이터 위치를 모은 지도
- 추출(아이디어·할 일)
  - O [아이디어] 동네 공원에 반려견 놀이터 위치를 모은 지도 만들기
- 채점: 1·2번은 true이고 3번은 false라서 따로 적을 이유가 없다. 추출한 [아이디어]는 정답의 반려견 놀이터 지도와 뜻이 같고, 사용자가 직접 낸 아이디어다. 저장된 노트는 [할 일]인 관리사무소 문의이고 아이디어 항목과는 다른 종류라서 중복이 아니다. 4번의 메모 목록은 비어 있다.

### 12. `saved-idea-and-open-questions` (11.8초)

- 설명: 아이디어를 이미 저장함. 답하지 않은 질문·정하지 않은 것은 메모가 아니다
- 제목: 걸으면서 영어 단어 외우는 오디오 앱 / 요약: 걸으면서 영어 단어를 외우는 오디오 앱을 만들자는 아이디어가 나왔다. 앱의 발음은 미국식으로 하고 싶다고 했다. 첫 시제품은 단어 100개 정도로 시작하려고 한다.
- 대화 중 저장한 노트: [아이디어] 걸으면서 영어 단어를 외우는 오디오 앱 만들기
- 정답
  - O 오늘 밤 영어 단어 목록 100개 정리하기
- 추출(아이디어·할 일)
  - O [할 일] 오늘 밤 영어 단어 목록 100개 정리하기
- 메모
  - O 영어 단어 오디오 앱의 발음은 미국식으로 한다.
  - O 첫 시제품은 단어 100개 규모로 만들 계획이다.
- 채점: 메모 2번("첫 시제품은 단어 100개 규모")은 사용자가 말하지 않았고 제니가 한 말이라 근거가 약하지만, 사용자에게 쓸모 있는 정보 형태라 진행 기록으로 보지 않았다. 1·2번 false 항목과 3·4번 true 항목은 없다.
